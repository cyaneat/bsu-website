# Новости БГУ: перевод интерфейса и кратких аннотаций (v5)

Языки: `ru`, `ky`, `en`, `zh-CN`. В комплекте переводы названий, кратких аннотаций и категорий **шести** новостей из текущего `newsRecords` (снимок редакционного каталога). UI поиска, фильтров, подробных страниц и дат также переводится.

Это **черновые переводы**, не подтверждённые редактором БГУ. Полные тексты и медиа ещё не мигрированы, ссылки на источник сохранены. Не заявлять, что полный архив новостей переведён.

Для CMS: хранить `title`, `excerpt`, `content` для каждого языка отдельно, с `status` (`draft`, `review`, `published`); не публиковать машинный перевод автоматически. Для SEO нужны серверные `/ru/news`, `/ky/news`, `/en/news`, `/zh-CN/news` и `hreflang` после миграции маршрутов, пока сайт использует общий URL и клиентский переключатель.
